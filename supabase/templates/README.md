# Supabase Auth email templates

Paste each file into **Supabase → Authentication → Emails → Templates**.

| Supabase template | Subject | File |
|---|---|---|
| Confirm signup | Your Delivrie confirmation code | `confirmation.html` |
| Invite user | You've been invited to Delivrie | `invite.html` |
| Magic link | Your Delivrie sign-in code | `magic_link.html` |
| Change email address | Your Delivrie email change code | `email_change.html` |
| Reset password | Your Delivrie password reset code | `recovery.html` |
| Reauthentication | Your Delivrie verification code | `reauthentication.html` |

The logo is served from `https://delivrie.io/assets/email-logo.png` (PNG, because Gmail and Outlook don't display SVG).
