Developer experience
Built like the tools
 you already love

        

        
The details that make email boring in the best way: predictable, debuggable and safe to retry.

      

      

        
Test mode
Send to delivered@, bounced@ and complained@test.delivrie.io without touching reputation.

        
Modular webhooks
Subscribe to exactly the events you need. Every payload is signed and retried with backoff.

        
Idempotent requests
Pass an Idempotency-Key and retries never double-send.

        
Plain REST, any runtime
JSON over HTTPS with clear error codes. No SDK to install and nothing to lock you in.

        
Batch sending
Up to 100 emails in a single request, each with its own variables.

        
Scheduled sends
Schedule in natural language or ISO time, and cancel any time before it sends.
