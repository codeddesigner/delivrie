Create domain

POST /domains

Add a sending domain. The response includes the DNS records to add at your DNS provider.

FieldTypeDescription
namestringrequiredThe domain or subdomain, for example mail.kora.ng.
regionstringSending region.
return_pathstringSubdomain used for bounces and SPF.
click_trackingbooleanRewrite links to track clicks.
open_trackingbooleanAdd a tracking pixel.
